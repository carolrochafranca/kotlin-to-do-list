# Roteiro de evidências

Capture imagens legíveis do emulador ou dispositivo depois de executar o app:

1. `01-lista-inicial.png`: lista inicial aberta.
2. `02-formulario-nova-tarefa.png`: formulário de cadastro aberto.
3. `03-tarefa-cadastrada.png`: nova tarefa visível na lista.
4. `04-edicao.png`: formulário preenchido ao editar uma tarefa existente.
5. `05-concluida.png`: tarefa marcada como concluída, com texto riscado.
6. `06-exclusao.png`: lista após excluir uma tarefa.
7. `07-navegacao.png`: ida ou retorno entre lista e formulário.
8. `08-build-ou-execucao.png`: saída de build bem-sucedido ou app em execução.

Evite capturas cortadas; mantenha visível o título da tela e a ação demonstrada.
